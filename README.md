# 🛡️ VPNMY - Автоматический сканер и чекер VPN серверов

Проект для автоматического тестирования VPN-серверов (VLESS / VMess / Trojan), измерения скорости, фильтрации рабочих серверов через **Xray Core**, генерации файла подписки `FL1PVPN` и мгновенной отправки в Telegram.

## 🚀 Как работает на GitHub (100% бесплатно и автономно):

1. **Автоматический запуск по расписанию:** каждые 30 минут сценарий **GitHub Actions** запускает чистую виртуальную машину Ubuntu.
2. **Тестирование:** Скрипт `main.py` скачивает источники, запускает `xray` и тестирует реальную скорость/пинг каждого узла.
3. **Обновление репозитория:** Рабочие серверы сохраняются в файл `FL1PVPN` и `stats.json`, после чего автоматически коммитятся в ветку `main`.
4. **Сайт / WebApp:** Страница **GitHub Pages** автоматически отображает актуальную статистику серверов в реальном времени.
5. **Telegram:** Бот присылает сообщение с количеством рабочих серверов и свежий файл `FL1PVPN` в ваш чат или канал.

## ⚙️ Настройка в репозитории (За 2 минуты):

### 1. Добавление секретов (Secrets)
В вашем репозитории перейдите в **Settings** ➔ **Secrets and variables** ➔ **Actions** ➔ нажмите **New repository secret**:

| Секрет | Значение | Описание |
| :--- | :--- | :--- |
| `BOT_TOKEN` | `123456789:ABCdef...` | Токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `TG_CHAT_ID` | `123456789` | Ваш Telegram ID от [@userinfobot](https://t.me/userinfobot) |
| `REMOTE_API_URL` *(опционально)* | `https://your-server.com/api` | URL вашего сервера для отправки `FL1PVPN` |

### 2. Разрешение Actions на запись в репозиторий (Workflow Permissions)
Чтобы GitHub Actions мог сохранять обновленный файл `FL1PVPN` в репозиторий:
1. Перейдите в **Settings** ➔ слева раздел **Actions** ➔ **General**.
2. Прокрутите вниз до блока **Workflow permissions**.
3. Выберите пункт **Read and write permissions** (Разрешения на чтение и запись).
4. Нажмите **Save**.

### 3. Включение GitHub Pages (Для сайта и Telegram WebApp)
1. Перейдите в **Settings** ➔ слева раздел **Pages**.
2. В блоке **Build and deployment** (Source) выберите **Deploy from a branch**.
3. В выпадающем списке выберите ветку **`main`** и папку **`/ (root)`**.
4. Нажмите **Save**. Ссылка на ваш сайт будет вида: `https://<ваш_логин>.github.io/VPNMY/`.

## ⚡ Как запустить проверку вручную прямо сейчас:

1. Перейдите во вкладку **Actions** вверху репозитория.
2. В левой колонке выберите **Auto Update VPN Subscription**.
3. Нажмите кнопку **Run workflow** ➔ зеленую кнопку **Run workflow**.
4. Через 1–2 минуты статус станет зеленым ✅, и вам в Telegram придет свежий файл `FL1PVPN`!
